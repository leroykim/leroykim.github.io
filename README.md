## One-Time Setup (Windows)

Install Ruby+DevKit from [RubyInstaller](https://rubyinstaller.org/), then run:

```powershell
ridk install
gem install bundler
gem install bundler:2.7.2
```

## Project Commands

```powershell
cd C:\research\gitlab\leroykim.github.io
bundle _2.7.2_ install
bundle exec jekyll serve
```
